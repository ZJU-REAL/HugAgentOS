# agent_client 集成

为本机 ACP 等外部智能体客户端提供会话租约：客户端在 `/v1/client-sessions/{chat_id}` 登记工作目录、权限档和自带的 MCP 服务，心跳续租，断开或关闭时释放。租约只存在于本进程内存，凭据不落库；仅本机模式、不受限的本人账号可用。

租约期间该会话的权限档以租约为准（每轮受理时冻结为 run_mode），客户端 MCP 只加入该会话的 run；没有租约的请求不能进入已被租用的会话。租约撤销或过期后的任何查询都抛错，不回落到账号权限。撤销时取消失败会保留不可用占位，直到引擎重启。

core 只依赖 `core.harness.registry.client_sessions` 端口；本模块在 `setup()` 中注册 `registry` 作为实现并挂载路由。FULL 和 CE 均安装。
