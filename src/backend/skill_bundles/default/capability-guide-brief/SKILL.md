# 能力清单速答技能

用于回答"这个智能体能做什么、我该怎么问、哪些问题适合问你"。

## Instructions
1. 识别能力咨询意图：如"有哪些能力""能做什么""我该怎么提问""可以问哪些问题""支持哪些图表/导出/文件"。
2. 先与真实清单对齐：以系统消息末尾 `# 可用技能` 和本轮可用的工具清单为准。下面的能力地图是骨架不是承诺——清单里没有的条目一律略去，不要照抄。
3. 先输出能力地图：按实际安装的能力分组说明，每类 1-2 句，避免空泛描述。
4. 再给提问模板：按用户关注方向给 8-12 条可直接复制的问题，覆盖研究、知识库、分析、图表、报告、文件等场景。
5. 提供提问技巧：强调时间范围、数据口径、任务目标（检索/分析/画图/导出）要明确。
6. 明确边界与优先级：只介绍当前实际可用能力；查不到数据要直说；外部信息注明来源与时效。
7. 收尾给下一步：给 1 个推荐追问，帮助用户从"了解能力"进入"实际办理/分析"。
8. 禁止把能力介绍写成长篇手册；保持结构化、可复制、可执行。
9. 不暴露内部机制：不要提"加载技能""调用 MCP""沙箱""SKILL.md"等实现细节，用户只关心能办成什么事。
10. 用户问的是某一类能力（如"你会做 PPT 吗"）时，只展开那一类并给 3-5 条模板，不要把 10 类全铺一遍。

## Inputs
- 用户关于能力范围、使用方式、可提问示例、功能边界的咨询
- 可选：用户关注方向（如联网研究、知识库、图表、报告、文件分析）
- 可选：用户希望的详细度（简版/中版/详细）

## Outputs
- `能力地图（按实际安装能力）`：
  - 智能问答与任务拆解：澄清目标、分解步骤、汇总结果，复杂任务可分阶段推进。
  - 数据库直连查询：连上已授权的业务库，探查表结构并按需取数。
  - 知识库检索：从已接入的知识库定位原文、摘要与出处。
  - 互联网检索与网页抓取：公开网页、新闻与财经资讯检索，指定链接可直接抓正文。
  - 数据计算与分析：同比、环比、占比、贡献率、拉动点数、趋势与异常识别。
  - 图表与可视化：折线图、柱状图、饼图、分组图、堆叠图（基于真实数据，不臆造数值）。
  - 办公文档产出：Word 报告与公文、Excel 表格与财务模型、PPT 汇报与路演、PDF 生成与合并拆分填表。
  - 文件与工作区：上传 PDF/Word/Excel/图片后摘要、问答、对比、异常识别，产物统一钉到工作区可下载。
  - 批量执行与定时任务：对一批对象套同一个任务先出计划再逐条执行；周期任务可按时自动跑并投递结果。
  - 能力中心扩展：在能力中心按需增减智能体、技能、连接器、插件，装完即刻可用。
- `可直接提问模板（示例）`：
  - 检索取数类：
    - `搜索今天的主要科技新闻，并按来源整理要点。`
    - `从知识库找到项目验收要求并列出原文出处。`
    - `分析这份 CSV 的关键指标与异常值。`
  - 研究分析类：
    - `比较这两份材料的主要结论和证据差异。`
    - `为这个主题设计一份可执行的调研提纲。`
    - `把检索结果按时间线整理，并标出不确定信息。`
  - 文档与报告类：
    - `总结我上传的文件，并列出待办事项。`
    - `根据已有材料生成一份结构化研究报告。`
    - `从知识库提取相关章节并比较观点。`
  - 计算与可视化类：
    - `帮我计算表格中各分类的占比和同比变化。`
    - `根据这组时间序列画一张折线图。`
  - 文档产出类：
    - `基于以上分析生成一份Word报告并导出。`
    - `把这组数据做成一份带图表的Excel看板。`
    - `按这份提纲做一套汇报PPT。`
  - 文件与自动化类：
    - `[上传文件] 帮我对比这两份报告的主要差异。`
    - `每周一早上九点汇总上周的关注话题发给我。`
- `提问技巧`：
  - 明确时间：`2024年`、`2025年1-3月`、`近五年`。
  - 明确口径：字段含义、统计范围、单位与缺失值处理方式。
  - 明确目标：`查数值` / `做分析` / `画图` / `导出` / `读文档`。
  - 明确产物形态：要 Word 还是 Excel 还是 PPT 还是 PDF，一次说清可少来回一轮。
  - 复杂任务分步：`先查数据 -> 再分析 -> 再画图或导出`。
- `边界与可信度说明`：
  - 无数据时必须明确告知，禁止编造。
  - 关键结论尽量附来源（数据库/知识库/公开链接）。
  - 优先使用用户指定或已接入的数据源；互联网信息用于补充并注明出处。
  - 外部信息可能存在更新时滞，需要提醒用户核对发布时间。
  - 能力清单里没有的事情直接说做不了，并指出可以在能力中心装哪一类能力来补齐。

## Response Template
1. `你可以问的能力范围（按当前已安装能力）`
2. `你可以直接复制的问题（8-12条）`
3. `提问建议（时间+口径+目标）`
4. `边界说明（数据与时效）`
5. `下一步建议（给1条可立即执行的追问）`
