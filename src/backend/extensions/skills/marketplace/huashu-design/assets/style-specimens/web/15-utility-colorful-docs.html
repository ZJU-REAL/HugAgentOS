核心命令

rollcall check

逐项检查仓库里的成员名单是否与上游一致，并给出可直接执行的修复建议。

基本用法

终端rollcall.toml
# 检查当前目录，只看有差异的项
$ rollcall check --diff-only --format table

✗ 3 项不一致    ✓ 41 项通过
  members/lin.toml   缺少 role 字段
提示：在 CI 中加上 --strict，存在差异时会以退出码 1 终止。
--diff-only过滤只显示有差异的项
--format输出table / json / junit
--strictCI存在差异时退出码为 1
