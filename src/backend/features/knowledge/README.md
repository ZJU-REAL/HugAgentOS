# 知识库

拥有知识空间、文档、分块、媒体资产、Wiki 模型、权限、索引队列和外接知识库路由。FULL 与 CE 均安装模型；用户删除清理随模型注册，独立于运行开关。CE 通过 edition.py 选择权限、外部 provider 和请求模型。

解析、分块、语义切分、媒体描述与索引分别归属对应模块。向量存储的客户端、索引写入和检索各自维护职责；共享 embedding/reranking 客户端位于 core.models，由所有领域复用。缓存仍为进程内唯一所有者，调用方引用明确模块，不保留旧路径转发。

核心通过 catalog_options 取得管理选项，通过 retrieval_context 取得外部 MCP 请求上下文。模型请求头由宿主注册的环境解析器处理，知识库和模型层不直接依赖桌面实现。实际桌面身份校验与设备头逻辑保持在原桌面模块，P5 随其目录归属移动。

API 按原端点顺序组合为一个中央路由入口。依赖 core 的模型、存储、认证、数据库及通用解析接口。独立模型加载与空库升级必须验证，测试使用隔离数据库和模拟外部模型/向量服务。

版本差异统一由 edition.py 选择权限、外接 provider、检索、请求模型与初始授权；CE 只覆盖此入口。
