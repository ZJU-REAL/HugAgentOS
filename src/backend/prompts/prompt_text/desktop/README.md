# 桌面端提示词

此目录仅用于桌面本机执行。版本池 kind 为 `desktop`，沿用提示词管理的创建、克隆、编辑、激活、删除及导入导出。默认版本首次 seed 后保存到数据库；已有版本不会被文件覆盖。数据库无活动版本时回退这些文件。

片段 ID 是文件名去掉 `.system.md`，运行时按场景选取，不是全量拼接。请保留 ID。禁用或删除活动版本内的片段会停止注入该片段，不再逐片回退文件。

- environment：`{environment_xml}` 来自实际工作目录、系统及版本、架构、runner Bash 解析器、时区、权限策略与授权目录。
- guidance：本机文件与执行通用规则。
- windows：只在实际 Windows 主机注入；macOS/Linux 不注入。
- project / project_missing：绑定项目且有/无路径，变量 `{project_name}`、`{local_path}`。
- project_instructions：变量 `{instructions}`。
- bash_tool：Bash 工具说明，变量 `{cwd}`。
站点流程统一由站点插件的 site-builder 技能按需提供；本目录不再包含站点规则或记录。编辑时通过 list_sites 获取最新记录，不在智能体装配时预查询。

模板使用 Python format 语法，字面花括号写成 `{{`、`}}`。环境 XML 作为变量一次填充，不再次解释其中内容。

Config → 提示词管理 → 桌面端 → 完整预览：预览选定的已保存版本（无需激活），展示默认模式、未绑定项目的系统提示词、桌面规则、适用代码能力段、Bash 工具说明，并单列条件片段。云端管理后台使用明确的运行时占位符；本机后台采集本机真实环境，但使用独立预览会话和 ask 权限档。本机后台优先复用完整智能体装配，包含可用工具与动态提示词；无法装配时明确标记模板预览。云端仅模板预览，不代表某个现有会话的工具、技能及 MCP 动态快照。

CE 与 EE 使用同一份 `components/prompts` 编辑器和 `prompt_management` 路由，权限复用 `require_system_settings`。CE 的 `/config` 仅提供提示词管理，并可从设置中的“提示词管理”进入，不包含商业管理模块。桌面预览支持保存版本和编辑抽屉中的未保存内容，预览不写入数据库。分类标签、可见性和预览入口统一由版本池 metadata 提供。

双后端桌面 Config 可显式选择云端或本机；整个编辑器的列表、编辑、激活、预览与快照请求始终使用同一目标。切换目标关闭旧编辑状态，避免跨库保存。
