# 工作台角标、通知与后台运行

应用声明 permissions 中的 badge、notification、background 分别请求三项能力。
workspace 模块还须声明 grants：badge.update、notification.show、background。
用户在宿主控件中逐项审批。SDK 请求和插件自报 gesture 不产生授权。

已打开实例可调用 SDK updateBadge(connection, count) 和 showNotification(connection, {title, body})。
角标为 0–9999 整数，每实例每十秒最多五次。通知标题最多 80 字符，正文最多 240 字符，
只能显示纯文本；控制字符与双向文本控制符被拒绝。每实例每分钟最多三条，每用户每分钟最多十条。
界面最多保留二十条通知，五分钟后过期。点击打开只调用宿主应用导航；通知不能指定 URL。

角标保存为受控投影，最长保留一小时。关闭页面后可显示该投影；读取目录和角标不会创建 iframe 或进程。
工作台两种侧栏与更多菜单使用同一角标状态，可访问名称包含未读数量和后台状态。
身份、安装、版本或授权失效后隐藏并清理相应状态。不能按应用名称或 slug 回退到另一个来源。

后台运行不会自动启动应用。用户只能将已打开应用拥有的真实资源转入后台。
这需要独立的 background 审批。资源仍使用原资源服务的所有权、执行来源、资源预算和清理器。
每用户最多两个后台资源，每应用最多一个；租约最长九十秒，单次运行最多十五分钟。
工作台提供续期和停止按钮。租约过期、撤销、卸载和退出均停止实际资源。
后台授权不替代资源授权，普通资源租约也不产生后台授权。

这些权限按账号、准确应用 key、安装与版本、服务来源隔离；升级后需要重新确认。
JSON 写接口使用既有身份和 CSRF 边界。活动数据保存在独立 workbench_activity 内容块中，
不修改既有聊天、托管业务应用、导航偏好或真实业务文件。
