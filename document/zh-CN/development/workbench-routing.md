# 工作台应用地址与插件导航

插件应用使用 `/apps/<URL编码的applicationKey>/*`。applicationKey 从授权目录取得，包含准确安装身份。不要用名称或插件 slug 替代它。内置业务仍使用原有地址。

应用中心、两种侧栏与更多菜单使用同一个打开入口。URL 保存当前子路径、查询参数和片段。刷新、深链接和浏览器前进后退会恢复当前位置。声明中的 `views[].path` 为相对路径，例如 `reports`；宿主显示二级导航，并按最长路径匹配更新标题和焦点。

独立 SDK 提供 `workspaceNavigation(connection)`。调用 `navigate('/reports/details')` 请求当前应用内导航。使用 `onChange(listener)` 渲染已应用的宿主路由。回调不得再次发送同一导航。宿主更新携带 `{path, requestId}`；请求身份用于确认与去重。插件不能指定其他应用键、外部网址或父目录。SDK 不提供宿主 store 或浏览器凭据。

页面分别显示目录加载、目录故障、无可发现应用、应用禁用与环境不支持。目录故障允许重试并保留 URL。无权发现与不存在使用相同提示。禁用插件仍不出现在普通目录中；已授权的准确深链接可显示禁用原因。启动和资源获取继续独立鉴权。

一个应用可以在二级视图中引用自己的 workspace 模块。启动接口只接受主模块及该应用声明的二级模块，不接受安装中其他未声明模块。

此功能没有数据库结构迁移。旧 UI v1/v2、托管应用接口和旧业务地址保留原有契约。

目录为空时保留深链接并显示空状态。准确应用查询的网络或服务器故障显示重试，不误报为无权限或不存在。
