# 浏览器自动化插件

在插件市场安装并启用「browser-automation」，然后在对话中请求浏览网页、操作表单或测试网页。智能体调用 `browser_open` 时，右侧 Canvas 自动显示该会话的真实 Chromium 浏览器；后续操作使用返回的同一 `resource_id`。

## 使用

- 浏览器支持导航、后退、前进、刷新、多标签、页面观察、定位器操作和截图。
- 点击「接管浏览器」后可以使用鼠标、键盘、中文输入和粘贴；智能体暂停观察和操作。操作完成点击「交还给智能体」。
- 登录、验证码等场景先勾选「私密登录」再接管。点击「保存登录」将登录状态加密保存；明确提供恢复编号，让智能体调用 `browser_open(checkpoint_id=...)` 恢复。密码和 cookies 不作为工具输出。
- 上传文件总大小上限为 8 MiB。浏览器下载可以从 Canvas 文件列表保存；需要保留为对话文件时，让智能体调用 `retain_download`，之后关闭浏览器也可以访问该文件。
- 关闭 Canvas 停止观看；「关闭浏览器」结束会话。断线重连不会重复执行先前的操作，人工操作断线后需要重新接管。
- 面板显示「本机浏览器」或「云端浏览器」。云端 `localhost` 指云端运行环境，不能用来访问用户电脑上的服务。

## 运行与配置

宿主负责资源鉴权、安装版本绑定、生命周期、画面传输和输入桥接。浏览器策略、工具、技能、脚本和前端界面属于插件包。内部服务端口和凭据不会发送到 iframe。

Docker 使用沙箱镜像内的 Python Playwright 与 Chromium；桌面完整包携带匹配的私有浏览器运行时，无需用户另装 Node.js。镜像构建和离线包构建执行真实浏览器表单、截图检查。更新本功能需要同步后端、MCP、沙箱镜像、前端及相关桌面客户端，不能只更新前端页面。

部署前升级数据库到 `browserassets02`（`alembic upgrade head`）。迁移增加资源、票据、登录状态与包资产表，不改写现有业务行。备份后可用 `alembic downgrade historydisplay01` 回滚；回滚会删除新增表中的会话和登录状态。先停止使用浏览器并回滚应用版本，再回滚数据库。

| 环境变量 | 默认值 | 作用 |
|---|---|---|
| BROWSER_DNS_RESOLVER_URL | 空 | 可选受信任 HTTPS JSON DNS 服务；用于 Fake-IP 环境，解析结果仍执行私网检查 |
| `BROWSER_ALLOWED_HOSTS` | 空 | 逗号分隔的精确主机白名单；可明确允许内网测试主机 |
| `BROWSER_ALLOW_PRIVATE_NETWORK` | `false` | 允许常规私网访问；链路本地、云元数据、未指定及组播地址始终禁止 |
| `BROWSER_CHROMIUM_SANDBOX` | `true` | 启用 Chromium 沙箱；容器 root 由外层容器隔离 |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE` | 空 | 管理员显式指定执行环境内的 Chromium 路径 |
| `PLUGIN_RESOURCE_MAX_PER_USER` | `8` | 单用户活动资源上限 |
| `PLUGIN_RESOURCE_IDLE_SECONDS` | `1800` | 没有观看者且无操作时的退出时限 |
| `PLUGIN_RESOURCE_TTL_SECONDS` | `86400` | 资源总寿命 |
| `PLUGIN_RESOURCE_RECONCILE_SECONDS` | `30` | 失效资源清理检查间隔 |
| `PLUGIN_RESOURCE_SECRET_KEY` | 空 | 稳定的资源加密密钥；可沿用 `EMAIL_SECRET_KEY` 或 `ADMIN_TOKEN` |
| `BACKEND_INTERNAL_TOKEN` | 现有内部回调配置 | 后端与内置 MCP 共享的调用签名密钥，云端必须配置；本机运行时可使用其随机 runner 密钥 |

本机未配置加密密钥时，在私有数据目录创建随机密钥，不使用固定开发密钥。保留该密钥才能恢复之前保存的登录状态；不要将密钥写入插件包或仓库。云端未配置加密密钥或内部调用签名密钥时拒绝创建或操作浏览器。

默认仅允许公开网络；SOCKS 传输检查 DNS 实际解析地址，并连接同一受检 IP。桌面默认权限档还禁止读取本机状态和凭据目录，仅为运行时依赖开放必要读取范围；缺少系统隔离能力时拒绝运行，不静默降级。

插件模块的脚本和样式通过短期只读资源票据加载。票据绑定资源、用户会话和安装版本，登录撤销后失效；模块仍保持隔离 iframe，不能直接调用业务接口。技能包含操作流程与参数参考，连接器的四个工具分别提供用途说明。更新已安装插件后，旧版本浏览器需要重新打开。


### 浏览器面板（1.0.2）

标签栏复用 MIT 开源 [chrome-tabs](https://github.com/adamschwartz/chrome-tabs) 的样式和 SVG。
标签栏的“＋”创建真实标签页；点击标签切换页面；“×”关闭标签。
地址栏支持输入网址并按 Enter，另有后退、前进和刷新。
不再显示独立的接管、登录、保存登录或关闭浏览器按钮。

网页视口跟随 Canvas 的宽度和高度调整。用户直接点击、滚动或输入时自动取得连接专属控制权。
操作期间暂停智能体读取。焦点离开面板或停止操作 15 秒后自动交还控制权。
中文输入法组合期间和鼠标拖动期间不会自动交还。
此面板不提供保存登录入口，不会自动保存登录；已有登录恢复编号仍可用于恢复。


### 单层标签栏和滚动（1.0.3）

浏览器面板只显示一层网页标签栏。全屏、收起和其他 Canvas 内容的切换入口位于同一行。
模块通过通用 canvas_header 声明自行提供标签栏，宿主不再重复显示“浏览器”容器标签。

首次滚轮操作会取得控制权，并将鼠标位置和滚动量发送给远端页面。
连续滚轮和鼠标移动会合并发送，避免堆满操作队列。
队列过载与实际断线分别报告；重连后会清除旧连接报错。


### 1.0.4 统一标签与功能选择页

所有 Canvas 标签采用同一 MIT Chrome Tabs 外观。点击加号打开宿主功能选择页，不预先创建空白网页。用户确认网址后，浏览器插件新增网页；也可上传并预览文件、进入能力中心、选择已启用插件的快捷功能或返回已打开内容。取消选择页保留原内容及未保存编辑。插件快捷功能仅填写对话输入，需用户自行发送。未提供的终端等功能不会显示为可点击入口。


### 1.0.5 地址导航与滚动修复

浏览器地址栏会去除首尾空格，并为不带协议的网址补上 HTTPS。首次打开显示网址输入提示；从功能选择页打开第一个网址时复用初始标签，不遗留额外空白页。人工导航在主文档开始加载后返回，网页继续加载，避免慢脚本阻塞后续操作。智能体导航仍等待 DOM 就绪。网页使用原生滚动条，可使用滚轮或拖动滚动条；相同尺寸的调整不会中断当前输入。更新插件后重新打开浏览器，新会话使用新版本。

### 1.0.6 浏览器动作响应优化

浏览器动作完成后直接返回缓存的标签状态，不再逐个等待所有网页的标题读取。加载事件和有界后台刷新更新标题；页面执行长脚本时暂时保留已有标题，不阻塞其他标签的操作。动态标题在后台刷新后显示。智能体导航仍等待 DOM 就绪，页面定位、控制权和网络策略保持原有语义。升级插件后重新打开浏览器会话。

### 1.0.7 滚轮与 Bing 搜索

点击网页后，鼠标停在原位置也可以滚动；隐藏的输入框不再截获鼠标事件，键盘和中文输入法继续工作。地址栏和新标签页输入统一支持网址与搜索：域名、IP、localhost 和明确的 HTTP(S) 地址直接打开，其他文字通过 Bing 搜索。搜索仅在提交后发送，不发送输入建议请求。不安全协议和带凭据的网址会被拒绝。

### 1.0.8 缩放与触摸滚动

新标签默认 100%。可用 Ctrl＋、Ctrl－调整网页缩放，Ctrl＋0 恢复 100%；macOS 也支持 Command。工具栏提供缩小、比例重置和放大按钮。缩放会调整远端页面布局，完整画面按比例放入面板，不裁掉视口边缘。超出视口的网页内容仍通过滚动查看。每个标签独立保存当前面板中的比例，缩放档位受允许的视口尺寸限制。

触摸屏轻点执行点击，单指滑动执行滚动，不再把滑动当成鼠标拖选。多指和取消手势不发送点击。中文输入、鼠标拖选和滚轮操作继续可用。升级后重新打开浏览器会话。

### 1.0.9 标签切换修复

网页链接或弹窗打开新标签后，Canvas 自动切换到新页面及其画面。关闭当前标签优先切换到右侧相邻标签，没有右邻时切换到左邻；关闭后台标签保留当前页面。切换标签同步更新地址栏，空白页自动聚焦地址输入；同一标签的后台状态刷新保留未提交输入。窄面板中标签过多时可横向滚动，新活动标签自动进入可见区域。加号仍先打开功能选择页，取消不创建网页。更新插件后重新打开浏览器会话。


### 桌面本机安装

混合模式下，云端安装的浏览器插件使用云端浏览器。本机浏览器需要通过插件管理的本机安装入口导入 `browser-automation` 插件包；选择本机安装的完整标识加载，避免与同名云端插件混淆。当前用户拥有的本机插件参与对话装配，旧的共享本机引导插件不覆盖云端账号能力。

加载当前用户的本机插件时，桌面服务在回环地址按需启动其声明的内置 MCP 服务，并沿用品牌隔离端口、看门狗和关闭时进程回收。其他业务连接器继续使用云端网关。网关调用内置 MCP 时按已认证的账号和当前对话重新生成调用凭证，不转发设备提供的凭证给云端内部服务。

浏览器初始化完成后才报告就绪。实时画面只保留一个正在解码的帧和一个最新待处理帧，避免慢速设备累积旧画面。标签页切换或连接中断会丢弃过期画面；浏览器状态有变化时才更新标签页等界面。

沙箱绑定到用户和对话后，主机按已启用插件的 resource.prewarm 声明异步启动空白浏览器。首次 browser_open 原子接管同一安装版本的预热资源；如果仍在启动，则等待同一次启动完成。预热资源计入用户配额，空置五分钟后由资源回收器关闭；沙箱销毁、回池及后端退出时清理。带 checkpoint_id 的打开仍单独创建浏览器并恢复显式保存的状态。
