# 本机与云端技能、插件管理

技能管理工具由 `skill-manager` 插件提供，插件管理工具由 `plugin-manager` 插件提供。安装管理插件后才会提供对应工具。两个插件不提供启停工具；页面原有开关继续保留。

## 安装与管理

| 操作 | 本机执行 | 云端执行 |
| --- | --- | --- |
| `install_skill` / `install_plugin` | 读取绝对目录或 ZIP/TGZ，校验后写本机能力仓及安装登记 | 读取当前账号拥有的云端包产物，写云端私有库 |
| `list_*` / `get_*` | 读取本机登记、版本及组件 | 读取云端私有安装 |
| `update_*` / `uninstall_*` | 使用精确安装 ID 与 `expected_revision` | 使用精确安装 ID 与 `expected_revision` |
| `upload_skill_to_cloud` | 仅已绑定云端账号时提供；上传独立技能并注册云端私有副本 | 不提供；技能已在云端 |

本机安装参数：

```json
{"source":{"kind":"local_path","path":"/absolute/path/to/my-skill"}}
```

Windows 使用真实绝对路径，例如 `C:\Users\Example\skills\my-skill`。不用 `/myspace`，也不需要 `sandbox_get_artifact`。

云端安装参数：

```json
{"source":{"kind":"artifact","artifact_id":"owned-cloud-package-id"}}
```

更新前先 `get_*`，将返回的 `install_id`、`revision` 与完整新包传给 `update_*`。版本变化会拒绝覆盖。插件所属技能通过插件整体管理，不能单独修改或删除。

## 页面与运行时

本机工具安装、页面上传和页面手写技能使用同一套本机安装服务。技能页展示独立技能；插件页展示插件，其详情展示子技能和连接器。工具成功后刷新共享目录状态，无需重新打开应用。

本机安装目录由桌面端注入的 `HUGAGENT_CAPS_ROOT` 决定，版本文件位于 `skills/local/<key>/<revision>` 或 `plugins/local/<key>/<revision>`。安装先复制并验证输入，然后发布不可变版本与登记，不依赖原输入目录继续存在。卸载撤销登记并保留原输入和历史版本；把文件放到扫描目录只会提示待导入，不会隐式安装。

已安装不等于依赖齐全。外部运行时、连接器或账号缺失时应查看可用状态。插件包不接受内联连接凭据；凭据配置使用专门的连接入口。

## 上传、市场发布与文件预览

`upload_skill_to_cloud` 保留本机安装，目标为当前账号的云端私有技能。首次上传绑定稳定云端 ID；重试复用请求身份。更新已关联副本需提供 `expected_cloud_revision`，避免覆盖其他端的新版本。

市场发布是独立动作：使用云端技能 ID 申请审核。上传云端不等于上架。

`pin_to_workspace` 用于交付或预览，既不安装技能，也不搬移输入文件。本机路径、工作区预览引用、云端产物 ID 是不同标识，不可混用。

## 升级

官方管理插件升级到 2.0.0，并携带版本化执行声明。本机只执行已安装且声明匹配的管理能力；未知协议版本明确要求升级，不回退到云端操作。

启动时旧个人技能、旧本机插件迁到本机能力登记，并保存加密回滚快照。旧官方管理插件同步更新创作说明和工具声明。迁移失败保留原数据库记录；包含旧内联凭据的插件需先完成安全重配，不能将凭据复制进包。混合模式的共享默认插件继续以认证云端同步为准。

### 云端安装故障排查

升级云端时需同时应用数据库迁移（标准后端启动入口会执行），并更新后端和 MCP 服务。迁移 `capids01` 将 `content_blocks.id` 扩为 128 字符，保留技能版本、工作副本和安装回执的原有 ID 与内容。若返回 `Database field length limit exceeded (SQLSTATE 22001)`，应检查数据库迁移是否完成，而不是重新打包技能。其他数据库故障返回可用的 SQLSTATE，不返回 SQL 或绑定参数。

降级前若存在超过 64 字符的 ID，迁移会停止，避免截断版本和回执。应先备份并制定这些记录的数据迁移方案；不要直接删除或截断记录来强制降级。

## 在市场详情中更新或切换版本

管理员打开技能、插件或智能体市场的详情，在标题右侧使用「更新版本」和版本列表；
连接器在 Config 后台的 MCP 市场详情中使用相同控件。没有独立的能力版本管理页面。

先点击「下载当前版本包」，编辑包内内容，再上传 ZIP。技能包包含 SKILL.md，
插件沿用原有插件清单；智能体包只含 agent.json，连接器包只含 connector.json。
资源身份必须保持一致。版本号由后台递增，默认补丁 +1，可选次版本或主版本；
上传文件内的版本字段不能决定发布版本。历史非数字版本首次更新从 1.0.1 开始。

ZIP 上限 20 MiB，解压总量 50 MiB，单文件 10 MiB，最多 1000 项；
拒绝路径穿越、链接、重复路径、加密包、异常压缩比及凭据文件或内联凭据。
智能体能力绑定和 MCP 连接/认证/工具定义变更继续通过现有编辑、审核和重新验证入口，
版本包不能绕过这些流程。

列表显示当前版本和至少五个历史版本。选择历史版本并确认后，恢复对应完整内容和原版本号；
之后更新从已发布的最高版本继续递增。通过原有入口重新发布后，在下一次更新或切回旧版本前会保存该版本快照。
内置技能会同步运行时内容；其他市场资源的已安装副本由原有安装/配置流程管理。

## 默认交互可视化插件

「交互可视化」（visualize）随安装包提供，并在 CE、EE 和本机服务启动时默认安装一次。既有数据库也会补装。本机遵守安装器的默认插件开关；混合模式继续由认证云端同步能力。管理员卸载后，后续启动不会重新安装；已有禁用设置保持不变。

插件用于图表、模拟、原理演示、地图和界面原型。生成的完整 HTML 通过现有文件卡片打开 Canvas 预览。常用绘图库随插件打包，导出时内嵌，不需要额外账号。交互状态只在页面本地使用，不发送给模型；预览沙箱可能禁止跨次打开保存状态。需要公开发布网站时使用站点插件。

## 插件账号连接

声明账号连接的插件（宜搭、飞书、钉钉、电子邮箱）在详情页显示登录状态和连接入口。
本机模式管理当前电脑的账号连接。混合模式可切换“本机”和“云端”；两端分别登录，
查询状态、登录、轮询和断开连接均访问当前选择的位置，凭据不会通过能力同步复制。

插件安装完成不代表运行依赖已安装。本机登录需要对应 CLI；宜搭还需要 Node.js 和 Bash。
新版完整桌面包携带固定版本 OpenYida 及其锁定依赖，复用随包浏览器的私有 Node，
无需另装 Node/npm。其他插件仍按各自要求准备 CLI；无 Docker 单机部署也可使用已安装的 CLI。
云端连接使用服务器的运行依赖。本机服务尚未就绪时不会改用云端登录。

宜搭本机登录将 Cookie 保存在当前本机用户的持久目录，后续会话读取技能时使用同一目录。
退出账号连接会清除该目录中的登录 Cookie，不清理其他用户或云端的登录态。

此修复需要更新云端后端和完整桌面包。旧的云端插件快照须重新“同步云端能力”；
旧的本机导入插件须通过原包更新安装以补齐连接声明，无需删除账号或数据库。
