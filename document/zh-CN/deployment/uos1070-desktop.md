# UOS 统信 1070 aarch64 桌面端

> [English](../../en/deployment/uos1070-desktop.md)

UOS 1070 aarch64 使用仓库中的 `desktop-uos/` Electron 43 发行线。交付格式固定为
Debian ARM64 `.deb`；它不依赖系统 WebKitGTK 4.1，因此不受 Tauri 2 在 Debian 10 / UOS
1070 上的 WebView 依赖阻断。

## 支持范围

| 项目 | 生产基线 |
|---|---|
| 操作系统 | UOS 1070 桌面版，aarch64 |
| libc | glibc 2.28 |
| 桌面壳 | Electron 43.4.1 |
| 安装包 | Debian `arm64` `.deb` |
| 本机运行时 | 私有 CPython 3.11，`aarch64-manylinux_2_28` 锁 |
| 数据目录 | `~/.hugagent` |
| 配置目录 | `~/.config/com.hugagent.desktop` |

完整包支持本机、云端和双模式，能力与现有桌面端一致：deep-link 登录、回环反代、流式
对话、托盘/快捷问答、原生通知、本地文件夹项目、双上游路由、身份与模型配置桥接、离线
本机服务安装/升级/回滚、SHA-256 验证更新。

UOS 窗口保留系统标题栏和窗口控制。“文件”菜单提供“新建窗口”（Ctrl+Shift+N）、
“新建对话”和退出；快速问答窗口保留不带菜单栏的紧凑布局。

发行品牌可以为完整包预设首启模式；固定双模式的发行版会直接进入一键初始化。初始化与
安装页使用与现有桌面端一致的光晕、轨道和进度高光动画，只显示阶段、百分比与可操作错误，
不在页面底部展示原始日志。日志仍保存在本机服务日志目录，便于排障。

## 构建与验证

完整包只能在原生 Linux aarch64 构建机生成，推荐直接使用 UOS 1070 构建机。x86_64
机器只能交叉生成不含 Python 运行时的精简包。

```bash
cd desktop-uos
npm install
npm test
npm run build
npm run verify:deb -- "dist/HugAgentOS UOS_0.5.15_uos1070_arm64.deb"
```

验收时至少检查：

1. `dpkg-deb --field <包> Architecture` 返回 `arm64`；
2. Electron 主 ELF 的最高 GLIBC 引用不超过 2.28；
3. 断网冷启动完整包，本机服务安装阶段没有 `pip install`、uv 或 Python 下载；
4. 本机、云端和双模式分别完成登录、SSE 对话、附件上传下载、文件夹选择和通知；
5. 双模式下云端项目进云端，本地文件夹项目进本机；
6. 使用测试版更新清单完成 SHA-256 校验、系统授权安装和重启。

UOS 与 Windows、macOS 共用同一个发布索引：客户端按自己的平台取更新，某个平台还没发包
时明确提示「当前平台暂无可用更新」，而不带平台参数的旧客户端读到的共同版本要等该版本
三个平台都发齐才前进。桌面端版本号三平台保持一致，构建时会校验。

具体命令、产物和发布步骤见 [`desktop-uos/README.md`](../../../desktop-uos/README.md)。

> Electron 43 官方支持计划在 2027 年 1 月结束。它是 UOS 1070 的当前兼容基线，生产
> 维护仍需跟进最新 43.x 补丁，并持续验证 Electron 44+ 后续迁移。

## 与当前 Tauri 功能同步

UOS 复用当前源码中的 React 前端与 CE 本机后端。重新构建完整包会带入最新能力来源、
本机启停、技能同步和工作目录逻辑；只更新云端不会替换已安装客户端的这些资源。

- “文件”菜单支持打开文件夹并进入本机项目对话；普通包可重新选择运行模式。
- “视图”提供放大、缩小、实际大小（Ctrl + +/-/0，或 Ctrl+滚轮）。缩放档位与 Tauri
  一致，保存在 `prefs.json`，新窗口和重启沿用；系统 DPI 保持原生处理。
- “帮助”、托盘和侧栏共用更新流程。后台订阅发布通知，仅提示新版；确认后显示下载进度，
  下载阶段可取消。安装仍校验 Ed25519 签名和 SHA-256，并由 UOS 系统授权。
  旧服务器使用低频检查，断线退避重连；并发检查不会重复安装。
- 回环反代在注入会话和桥接凭据前检查 Origin/Fetch Metadata；不带来源的直接请求被拒绝。
- 服务日志运行中轮转，每份最大 32 MiB，只保留当前和上一份。能力未就绪时的检查间隔
  从 500 ms 逐步增加至 15 秒。升级保留原 UOS 数据及能力目录，不自动迁移已有配置。

完整包还支持与 Tauri 相同的仅混合模式构建入口：

```bash
JX_DEFAULT_SERVER_BASE=https://agent.example.com npm run build:hybrid-only
```

该入口固定云端地址与双模式，必须提供云端地址；精简包不能用于仅混合模式。
完整 ARM64 离线包仍须在原生 aarch64 构建机完成构建和安装验收。
