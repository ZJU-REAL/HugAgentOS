# 我的空间文件挂载

网页和沙盒使用同一组文件目录。系统按当前用户生成目录清单。

## 权限

- 只读：浏览、预览和下载文件。
- 编辑：创建、修改、移动和删除授权目录内的文件。
- 管理员：具有编辑权限，并可管理成员权限。

用户无权查看的团队目录不进入挂载清单。只读目录使用只读挂载。
文件 API 在每次操作前检查权限。修改成员权限前，系统关闭该用户的沙盒。
若沙盒关闭失败，权限修改失败。管理员应恢复控制器连接后重试。

## 存储

云端沙盒使用 `SANDBOX_PROVIDER=opensandbox`。
全量 Docker 部署默认使用 `STORAGE_TYPE=s3`。也可选择 `oss` 或 `obs`。
分别配置对应的 endpoint、bucket、region 和访问凭据。
参数名称见项目根目录的 `.env.example`。
本机模式使用本地目录。

存储服务地址须同时允许后端和沙盒控制器访问。
S3 服务部署在本机时，请使用容器可达的服务地址。
容器内的 `localhost` 指向该容器。

## Docker 主机准备

在 Docker 主机上创建存储目录。将其绝对路径设置为 `HOST_STORAGE_PATH`。
对象挂载由每个沙盒独立的挂载服务持有。Docker 主机需向该服务提供 `/dev/fuse`。
控制器不再持有 FUSE 连接，无需共享传播目录或宿主挂载准备脚本。
沙盒文件操作仍使用普通用户。

## 存量文件迁移

独立文件导入命令已移除。迁移存量文件前，先备份数据库和对象数据，
暂停目标目录写入，制定并审核迁移方案。核对目标路径、同名冲突和文件内容，
保留源对象及文件引用。

## 验证

使用编辑者创建文件。确认网页和沙盒都能读取该文件。
使用只读用户尝试写入和删除。两项操作都必须失败。
撤回团队权限。确认该用户无法访问该团队目录。
验证成功后恢复用户操作。

## 限制

对象存储目录移动包含多个对象操作，不是原子的文件系统重命名。

OBS 的 V4 配置依据[华为云说明](https://support.huaweicloud.com/obs_faq/obs_faq_0274.html)。
OSS 的 S3 V2 签名依据[阿里云说明](https://www.alibabacloud.com/help/tc/oss/user-guide/0002-00000307)。

## 本机 S3 服务（CE / EE）

将 `docker/object-storage/compose.object-storage.yml` 加入 `COMPOSE_FILE`。
该服务使用独立数据卷。它不发布宿主端口，也不使用 Milvus 的数据卷。
配置 `S3_ENDPOINT=http://object-storage:9000` 和 `S3_BUCKET=hugagent-files`。
分别生成随机 `S3_ACCESS_KEY` 与 `S3_SECRET_KEY`，写入权限为 600 的环境文件。
先构建 backend 镜像，再启动服务。初始化容器创建缺失的桶，并检查访问权限。

已有部署切换存储前，先备份配置和数据库。复制有效文件与附件，逐对象校验 SHA-256。
保留源文件，完成验证后再切换 `STORAGE_TYPE` 并重建应用容器。
CE Docker 也默认使用 S3。桌面离线本机模式保留本地存储。

## 文件页面

文件页面提供文档列表、图片视图、文件夹导航和团队目录树。
列表、预览、搜索、上传和重命名均使用当前用户可访问的挂载目录。
只读目录提供浏览和下载，不显示上传、重命名或删除操作。

文件在 Canvas 中打开。文本、Markdown 和 HTML 支持在线编辑；Excel 使用表格编辑器。保存直接写入当前空间文件。只读目录禁止保存，服务端会在每次保存时检查权限。

查找文件按路径顺序返回。结果中的 next_cursor 用于继续查找；后续调用须保持路径和匹配模式不变。每页均检查权限，并从当前目录读取内容。翻页不保存文件副本或搜索结果，不支持按修改时间全局排序。搜索期间新增、删除或移动文件可能影响后续页。

### 挂载生命周期与控制器重启

首次挂载与恢复共用独立挂载服务，直接接入沙盒文件系统，不把 FUSE 宿主路径写入 Docker 启动配置。
控制器重启不会杀掉该连接。每次文件操作检查当前授权和实际挂载；沙盒重启后恢复同一容器的空间目录。
工作区文件和只读权限保留，同步 Docker 操作在线程池执行。

挂载服务没有 Docker socket。凭据通过私有输入流传递，不进入容器标签或环境变量。
删除和到期回收同时清理挂载服务；恢复失败保留沙盒与工作区。
旧版含 FUSE 宿主 bind 的沙盒需要单独安排数据保全迁移，不可原地改写 Docker 启动参数。

## 混合模式 MCP

混合模式的本机会话通过云端能力清单安装“我的空间”连接器。
纯云端会话继续直接访问沙盒挂载目录；纯本机模式不安装这个云端连接器。

MCP 接口位于 `src/backend/extensions/mcp_servers/space_files_mcp/`。
内置服务注册表为 `extensions/mcp_servers/registry.py`。每项分别声明
`installation=local/cloud/both`（本机、云端或两端安装）和
`exposure=process/desktop_gateway`（独立进程或桌面能力网关）。
空间连接器在云端执行，通过桌面能力网关提供工具，不启动额外的监听端口。
安装位置不代表账号授权；网关每次调用仍检查当前账号的目录权限。

连接器提供两个工具：

- `space_files_read`：列根目录、列目录、读文件。
- `space_files_write`：写文件、建目录、移动、删除。

只读 Agent 不显示修改工具，伪造修改调用也被拒绝。
修改操作使用统一工具审批：“逐项确认”询问写入和删除；
“替我批准”放行普通写入，但删除仍须确认；“完全放开”使用用户已有授权。
会话只读限制优先于所有审批档位。文件读写最大为 5 MiB，使用 Base64；
删除目录时目录必须为空。

执行端要求有效且与工具参数一致的审批票据。
缺失、过期或参数变更的票据不能发出网关请求。
桌面升级需同时交付新版内置后端和云端后端，并重新同步能力清单。

对象存储镜像使用 MinIO 官方 GitHub Release 中固定 SHA-256 的二进制文件。Docker 通过 docker/object-storage/Dockerfile.object-storage 构建此镜像。已有 Milvus 镜像和数据卷保持独立。
